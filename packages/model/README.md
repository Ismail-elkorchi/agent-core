# @agent-core/model

Provider-neutral typed input/output, capability revisions, immutable compiled requests and complete request accounting. This package owns no session relevance policy, persona, application configuration or persistence location.

`ModelRequest.messages` contains ordered `ModelInputItem` values. Message roles preserve system, developer, user and assistant authority; tool results carry original call identities. Ordered content parts represent text/images/audio/video/documents. `protocol` items contain adapter-owned `ProviderContextState`; `control` items carry explicit configuration updates. Unsupported kinds or role distinctions must fail at the adapter boundary. Binary images are normalized into immutable base64 by the owning decoder so JSON artifacts retain their data.

`ModelResponse.output` contains ordered `ModelOutputItem` values. `modelResponseOutput` reads explicit typed output or safe display/tool convenience fields, never generic raw response data. `modelOutputToInput` builds replay items. Provider state is a separately authorized resource with format version, exact model/endpoint compatibility, originating request/input identity, replay rules and optional immutable artifact or resumable handle. Ordinary history readers must not expose it.

`ModelCapabilities.protocol` declares the resolved endpoint, revision, roles/kinds, continuation, reasoning accounting, async calls, steering, transforms, tool choice and counting support. A missing declaration is conservative and cannot establish modern capability support. Provider-native response boundaries and steering delivery updates have typed stream events and exact identities.

`parseModelRequest`, `parseModelInputItem`, `parseModelResponse`, `parseProviderContextState`, `parseModelStreamEvent` and `parseModelProfile` validate and own boundary values. `assertModelRequestSupported` applies the resolved model capability contract.

`CompleteRequestEstimator` implements `RequestEstimator` for diagnostics, including tool arguments and all known media/control fields. Its UTF-8 heuristic is explicitly uncalibrated. `estimateItems` rejects unknown opaque/media costs. Production admission uses `accountModelRequest` or adapter `compileRequest` results and `assertRequestAccountingFits`. Components report counted/estimated/unknown status, method/version, uncertainty headroom, separate output/reasoning reservations and pricing semantics. A missing output policy or unknown input cost cannot silently become zero.

`compileModelRequest` owns the actual provider body, capability revision and canonical SHA-256 input identity. Serialized sections count once, with semantic media/opaque costs accounted separately. Adapters identify exact payload paths so arbitrary user JSON keys are never suppressed. Encrypted byte size is not its logical token cost. Provider counts can replace heuristic input estimates; unknown costs require an explicit allowance.

Provider `completeCompiled`/`streamCompiled`, and their session variants, send the admitted body with only transport framing added. Stateful sessions should use their own compiled methods to retain continuation behavior. Third-party providers without compilation expose only logical-request estimates, not proof of provider-visible bytes.

`ModelTransportOptions` carries cancellation and native admission independently of compiled payload identity. Providers must receive the original compiled object; adding a deadline never authorizes cloning or changing that object. A native frame's optional `retainedBody` represents provider-retained input counted alongside transmitted `body`; its input identity covers both. Bounded future parent output is an explicit additional input reservation for preauthorized steering.

`ModelNativeDispatch` provides the exact frame, source call bindings, delivery identity and `generationDeliveryId` before transmission. Hosts reserve one inference invocation per generation and extend its reservation when an additional required-result frame contributes to it. `ModelNativeResponseBoundary` supplies the exact causal request and required/pending call identities. The native stream remains alive while governed calls or admitted successors are outstanding. `ModelToolResultDelivery` and its owning parser distinguish transmission evidence from tool-effect and inference settlement. Status queries never retry a send. Runtime uses single-response boundaries; convenience `done` aggregates are not an execution/replay contract.
