# Terminal presentation

Shared terminal presentation for the application adapters. `MarkdownDocument` retains a markspan GFM document session and a width-specific presentation. Source offsets are half-open UTF-16 ranges; generated labels have no source range. Copying original Markdown, displayed text, and normalized code are separate operations.

Links expose only HTTP, HTTPS, and mail destinations and never open automatically. HTML and images remain literal descriptions. Parser resource errors leave the exact source accessible. Syntax highlighting uses Prism's token API; unsupported languages remain plain code.

Import reusable components from `@agent-core/tui` and external-editor and explicit browser-launch integration from `@agent-core/tui/node`. Applications own policy and session lifetime. Components use the consumer's terminal-ui peer instance; install local file dependencies as packages rather than symlinking across independently installed terminal-ui copies.

Shared components also provide source-selection copying, attributed note paging, history bookmarks, and retained list elements and renderer-derived navigation geometry. Source text stays exact in memory and storage. Clipboard transport preserves the selected source, including tabs and line endings.

Configuration components consume provider discovery/authentication capabilities and a single validated save operation. Conversation projections preserve run/turn/call identity; draft, queue, recall, source, notes, and settings components remain caller-controlled. Applications supply optional attachment readers, resource search, session names, export, and notifications. Node integrations keep private presentation preferences and unsent drafts separate from accepted history.


Tool activities distinguish invocation completion from domain outcome. `projectProgress` and `projectSessionEntry` accept an optional tool renderer after the label callback; renderers receive structured observations. Generic results use a neutral completed state, failures retain invocation-failure state, and executor uncertainty remains visible. A renderer exception produces a display diagnostic and bounded raw inspection without changing execution truth or model input. The optional `renderLocalToolObservation` adapter from `@agent-core/tools-local` renders local source, search, process, and mutation results.

`notesPanel`, `queuePanel`, `configurationPanel`, and `sourceInspectorPanel` return terminal-ui child definitions. Compose them with `createTuiChild`, retain the returned child state in the application's aggregate state, route one scoped envelope, and consume their explicit domain outputs. Removing a child cancels its scoped work; hiding a queued mutation retains the child until its outcome is delivered and the application has recovered the draft or reported the failure. The stateless `mountPanel`, `applyPanelResult`, and `cancelRemovedPanels` functions share generation allocation, result grafting, and cancellation for applications with a `panelGeneration` counter and an `overlay`. They do not retain state or interpret outputs. Pass all retained children to lifetime reconciliation, including hidden saving queues, and forward each retained child's subscriptions from the parent. Consume `close`, `saved`, and queue outputs explicitly; session, approval, visibility, refresh, and draft recovery decisions remain application-owned.

`applicationEventSource` attaches application subscriptions inside the existing runtime's source lifetime. Its sink owns admission, reliable delivery, replacement, and backpressure. Startup runs after attachment; removal detaches the producer. There is no separate pre-attachment message queue. The application still owns service shutdown and any terminal host it created.
